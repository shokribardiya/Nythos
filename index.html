01 Introduction

Local models forget. Nythos doesn’t.

Nythos is a local-first workspace that gives a model what it needs to remember, in a form it can trust: persistent memory, a bounded working set, and a compiled context packet.

It runs as an MCP server next to your model. Anything a model writes arrives as an unverified candidate, never as fact, and the workspace says so on the page the model reads.

02 The Nythos workspace

Four ideas, one bounded room.

The model never sees the whole database. It sees a small, compiled room, built for the goal in front of it.

M

Memory

Persistent, on disk, outside the model. Facts, decisions and uncertainties survive between sessions.

S

Salience

Not everything matters equally. Ranking decides which entries deserve a place in front of the model right now.

W

Workspace

A bounded set of active items for the current goal: constraints, decisions, facts, uncertainties, session notes.

C

Context

The workspace compiled into a single packet, labelled as stored data and not as instructions.

03 How it works

From memory to model, in six steps.

  1. MemoryPersistent entries, each with an origin and a confidence.
  2. SalienceEntries are scored against the current goal.
  3. WorkspaceThe highest-value entries are admitted into a bounded set.
  4. Conflict checkLexical check for negation and value mismatches between entries.
  5. ContextThe workspace is compiled into one packet. Model-written entries are tagged UNVERIFIED.
  6. Local modelThe packet is handed to whichever local model you run.

04 Nythos Plus
+

Adaptive effort for local AI.

Know when more thinking is worth it.

Nythos Plus is a runtime layer that decides how much effort a request deserves, from a direct answer to a verified or escalated one, instead of spending the same compute on everything.

07 Research

What we’re actually studying.

01

Global-workspace-inspired external architecture

A bounded, shared workspace that lives outside the model, borrowing its shape from global workspace theory. An engineering analogy, not a claim about what happens inside a network.

02

Persistent memory

Durable, inspectable storage with explicit origin, confidence and a promotion path from candidate to trusted.

03

Salience

Deciding which stored entries deserve attention for the current goal.

04

Bounded workspace

A hard limit on what is active at once, so context stays small and legible.

05

Context compilation

Turning workspace state into a single packet that is clearly marked as data rather than instruction.

06

Adaptive compute

Matching the amount of work to the difficulty of the request.

07

Effort sensitivity

Measuring how output quality changes as effort level changes. Not yet measured.

08

Verification

Checking results against constraints or evidence before they are returned.

09

Resource-aware inference

Treating tokens, latency and escalation as costs to be spent deliberately.

Scope

Nythos works only with what a model sends and receives. It has no access to hidden activations and no access to hidden chain-of-thought. Reasoning submitted as hidden thinking is rejected and not stored (test C6).
